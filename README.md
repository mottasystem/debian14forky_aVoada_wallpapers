# debian14forky_aVoada_wallpapers
Wallpaper Theme aVoada for Debian 14 forky

== Artwork Theme: aVoada ==

=== Concept ===
In Brazilian culture, "pipa avoada" refers to a kite soaring freely in the open sky, unconstrained and light. Derived from the verb *avoar* ("to fly without ties / to give wings to imagination"), **aVoada** symbolizes the spirit of free software: unbounded freedom, community-driven creativity, and lightness.
